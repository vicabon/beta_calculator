4 大獨立資料源與 Failover 設計

  1. Google Finance：透過試算表儲存格原生 =GOOGLEFINANCE() 評估即時與歷史收盤，再由 Apps Script 橋接讀取。
  2. Yahoo Finance Chart API v8：支援台股 .TW/.TWO 與美股；歷史取未還原 close（防除權息誤報），query1 遇限流自動切換 query2。
  3. TWSE / TPEx 官方 API（美股採 Stooq CSV）：盤中取 MIS 即時成交價 z（無成交自動降級 OpenAPI STOCK_DAY_ALL）；歷史取 STOCK_DAY 並自動解析民國年日期。
  4. FinMind OpenAPI：獨立驗證 TaiwanStockPrice / USStockPrice，支援匿名 300 次/時與 ScriptProperties Token 600 次/時。
