一、全功能搬遷至免費網頁的三大技術瓶頸與解法

🚧 瓶頸 1：瀏覽器 CORS 封鎖

純靜態託管（如單獨 GitHub Pages）受瀏覽器同源政策限制，無法直呼 Yahoo Finance、TWSE、TPEx、Stooq API。

✅ 解法：搭配免費 Edge Serverless 代理（Cloudflare Pages Functions / Workers），由伺服器端並行抓取並回傳乾淨 JSON。

🚧 瓶頸 2：GOOGLEFINANCE 無公開 REST API

=GOOGLEFINANCE() 僅限 Google 試算表內運作；外部網頁硬爬蟲違反條款且易觸發反機器人驗證。

✅ 解法：主力改採 4 個合法官方免費 API（TWSE/TPEx ＋ Yahoo v8 ＋ FinMind ＋ Fugle 富果；美股用 Yahoo/Stooq/FinMind/TwelveData），並可選配現有 GAS 端點當第 5 源！

🚧 瓶頸 3：雲端共享 IP 限流與 10ms CPU

CF Workers 免費版每次執行 CPU 上限 10ms（網路 I/O 不計入），且共享資料中心 IP 偶爾可能遭上游 429 限流。

✅ 解法：GitHub Actions 每日盤後解析大檔寫入 D1（歷史收盤永久快取）＋ Edge Cache 60 秒即時快取 ＋ 4 選 3 高可用降級！

三、推薦終極零元架構藍圖（Cloudflare × GitHub Actions × Local-First）

✨ 為什麼這個架構最穩健？

  • 完全零個資入庫：僅傳遞公開代號查詢股價，所有資產與退休試算 100% 留在使用者本機。
  • 歷史收盤永久快取：通過三源驗證（VERIFIED）即鎖定寫入 D1，冷啟動後歷史查詢幾乎零上游 API 消耗。
  • 免費配額安全餘裕大：每日 100 名活躍用戶僅消耗不到 Workers 配額的 1% 與 D1 配額的 0.5%。

⚠️ 必須事先落地的防護機制

  • 防第三方盜刷 Proxy：強制驗證 Origin 白名單 ＋ Cloudflare 單 IP 頻率限流，防止外部爬蟲耗盡免費額度。
  • 單次 CPU 控管：Worker 絕不下載全市場大檔；大檔解析一律交給 GitHub Actions 盤後處理。
  • 資料備份防遺失：提供一鍵「匯出 JSON / 匯出 .xlsx」，與現有 Google 試算表版雙向相容。
